# Selected projects

A collection of web tools and creative resources, grouped by the tasks they help with. Each entry explains the main workflow and links to the public product.

## Publishing and document workflows

### [CarouselDraft](https://carouseldraft.com/)
Turn a public article URL, pasted text, or a text-based PDF into an editable carousel. Review the AI outline and source passages, adjust the slides, then export a PDF for LinkedIn or PNG images for Instagram. Uploading to social platforms remains a separate step.

### [LineSheetDesk](https://linesheetdesk.com/)
Prepare wholesale line sheets and catalogs from a CSV or Excel product list. Keep product information together, apply customer discounts or fixed item prices, and export branded PDFs for individual buyers. Saved catalogs preserve the product and price details used for that version.

### [Welcome Book Builder](https://welcomebookbuilder.com/)
Organize vacation-rental arrival details, Wi-Fi information, house instructions, and local recommendations into a phone-friendly guest guide. Draft and preview the content before publishing changes to the same guide link. Publishing and PDF export require an annual plan.

### [Team Memory Book](https://teammemorybook.com/)
Collect coworkers' messages and optional photos for a retirement or farewell book. The organizer reviews and arranges contributions, then shares a digital reading link or a printable PDF. Contributors do not need an account; physical printing and delivery are not included.

### [Printable Patch](https://printablepatch.com/)
Combine coloring pages, word searches, and mazes into printable activity books. The free browser studio supports arranging pages for A4 or US Letter output. A separate signed-in workspace offers custom AI coloring-page generation using credits.

## Creative resources

### [TeslaWraps](https://teslawraps.art/)
Find PNG appearance templates and setup guides for the vehicle's 3D view in Tesla Paint Shop. Templates are organized by vehicle model, with instructions for app or USB transfer. These are digital appearances, not physical vehicle wraps. The site is independent of Tesla.

### [Brushory](https://brushory.art/)
Read digital-painting brush selection, file-format, and import guides for drawing applications such as Procreate and Photoshop. The public brush library currently has no downloadable resources listed, so the available starting point is the guides and drawing notes.

## AI workspaces

### [Rivya](https://rivya.ai/)
Compare image, video, audio, and chat models by supported inputs, availability, and credit cost. Create with available models and manage saved work in Rivya Studio. Check each model's current status rather than assuming every catalog entry can be used.

### [Kyeo AI](https://kyeo.ai/)
Work with image, video, audio, and chat models in one workspace. Compare each model's required media, available controls, and credit estimates before generating. Capabilities differ by model and by what is currently enabled in the workspace.

### [Veo3o1](https://veo3o1.com/)
Create videos with text prompts, first-and-last-frame inputs, or reference images through an independent Veo 3.1 service. Review the mode, settings, and credit cost before submitting. Generation requires sufficient credits; the service is not affiliated with Google.

## Everyday file tasks

### [Neatbo](https://neatbo.com/)
Use browser tools for PDF organization, image compression and conversion, text processing, ebooks, and structured data. Examples include merging PDFs, converting Markdown to Word, formatting JSON, and resizing images. Choose the tool for the specific input and output you need.
